# もみけして！プロデューサー

スマートフォン向け、3年間・36か月のアイドルスキャンダル対応ゲーム。

## プレイ

`index.html` を開きます。HTML・CSS・JavaScript・assets を同じフォルダ構成で配置してください。ビルドや外部APIは不要です。GitHub Pagesでは `momikeshi/` として配信します。

全200件の個別ニュース（通常180／深刻20）、固定三すくみ、裏工作、大炎上、永久離脱、5人の好意・告白、エンディング、共有、localStorageによる再開を収録。ユーザー提供のプロローグを採用しています。

三すくみの属性・深刻度は選択前の画面に表示しません。裏工作したニュースの真相は結果・履歴に表示しません。静的ゲームのためソースコード内のデータは閲覧可能です。

大炎上は1回、月を消費しない追加イベント。未使用の深刻ニュースを優先し、該当事件をすべて使用済みの場合のみ再燃を許可します。告白イベントの処理後に大炎上、通常月の繰上げの順で進行。好意と告白済み状態は離脱後も保持します。

称号の優先順位：孤独 → 伝説 → 愛され → スキャンダル王 → 普通。

## 構成

- `news.js`: 200件すべての個別原稿
- `engine.js`: 画面から独立した進行・判定処理
- `app.js`: プロローグ、画面、効果音、保存、共有
- `style.css`, `layout.css`: スマートフォン／PC表示
- `assets/cast.webp`: 5人×4表情のアトラス
- `assets/hero.webp`: タイトル用ライブステージ

## 検証

`node test-engine.cjs` で主要分岐と500回の完走を検証します。
`NODE_PATH=<linkedomをインストールしたnode_modules> node test-ui.cjs` でDOM統合を検証します。開発用依存 `linkedom@0.18.13` はゲーム実行時には不要です。

実ブラウザの描画・実機タッチ・Web ShareのOSダイアログ・音声の聴取テストは本環境では未実施です。

## 画像制作

ユーザーの `3518698A-7EFC-4B79-8974-29497A7EC008.jpeg` を参考に、組み込み画像生成で制作。

アトラスの指示：同一5人を5列×4行に配置。ララは黒髪ロング、リンはオレンジのポニーテール、ルゥは青いツインお団子、レイコは黒髪ショート、ローラは金髪。通常・喜び・困惑・照れの4表情。ネオンピンク／紫の高品質ゲームイラスト。未成年の2人は非性的な衣装・表現。

タイトル画の指示：同じ5人のK-POP風グループがピンク／紫／青のLEDとスポットライトのステージに立つ縦長キービジュアル。文字・UIなし。リン・ルゥは肌の露出を抑えたジャケットとパンツ。下部はタイトルを重ねられる暗色。

## 追加エンディング

`ending.js` と `ending.css` に独立実装。契約満了、人気5段階、在籍者のみの好意別メッセージ、共有、名前入力からの再プレイ。終幕の進行段階も自動保存。`test-ending.cjs` は人気の10境界値、好意80、離脱者非表示、全員離脱、既存パラメータ不変を検証。

## 音声

効果音はWeb Audio生成、画面上の♪ボタンでオン／オフ。Sunoの指定楽曲「韓流」は公開ページから音源保存に成功せず、現時点の配布物には含みません。音源の提供を受けたら同梱可能です。
